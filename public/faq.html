Alipay & Wechat Pay FAQ

Currency for Wechat Pay testing:
Please select HKD and EUR for Wechat Pay testing, because WechatPay uses different MIDs for each currency.

For Wechat Pay h5 flow, please select JPY for testing (need to enable JP acquirer first).

Channel selection:
Please select the correct channel to test H5 flow and QR code flow.

For AliPay, by default /paymentMethods will return alipay for web and alipay_wap for iOS & Android.

For Wechat Pay, /paymentMethods does not work as expected. Even if we pass iOS & Android, it will still return wechatpayQR. Therefore we manually add logics to block wechatpayQR for iOS & Android in /paymentMethods request.
